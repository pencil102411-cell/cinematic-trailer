# 6 素材：图像（MJ / GPT-image-2）

## 资产层级

按这个顺序做，前一层是后一层的参考：

1. **角色设定卡**：定妆、面部特写、正侧背全身、服装道具。每个主要角色一张。
2. **场景概念**：每个主场景一张空场景氛围图，定光线方向和色调。
3. **道具**：关键道具（武器、信物、手机界面、文件）。
4. **镜头关键帧**：每个要生成视频的镜头一张首帧；需要变形/匹配剪辑的镜头再加尾帧。
5. **字卡和片名素材**：字形、纹理底板、粒子/墨迹素材。

## 分工

| 用 | MJ | GPT-image-2 |
|---|---|---|
| 擅长 | 电影质感、光影氛围、空镜、大远景、抽象母题、纹理 | 多张参考图保持同一张脸、按设定卡合成新画面、中文字形、带字道具、改已有图 |
| 预告片里用于 | 冷开场空镜、世界观奇观、母题插入、纹理底板、片名背景 | 角色设定卡、所有带主角脸的关键帧、手机/短信/报纸/档案、片名字形、改表情/换服装/扩图 |
| 一致性 | 弱，靠情绪板 / P 码统一风格 | 强，每次带上角色的设定卡做参考 |
| 文字 | 基本不可用 | 中文可用，仍要逐字检查 |

参考图上限、分辨率档位这类参数各平台不同，以用户界面为准。

**委托**：
- MJ 提示词交给 **mj-cinematic-prompts**（纯英文，区分纯文字出图和情绪板/P 码模式）。
- GPT-image-2 的角色设定卡、场景概念、写实化交给 **character-scene-asset-prompts**。
- 本 skill 负责的是：每张图在预告片里的用途、构图要求、和哪个镜头对应。把这些作为输入交给上面两个 skill。

## 关键帧构图规则

- **画幅**：16:9 出图。成片要做 2.39:1 宽银幕时，主体放在中间 75% 高度内，上下各留出会被遮掉的区域。
- **首帧停在动作前一刻**：拔剑之前、回头之前、门开之前。动作交给视频模型。
- **给动作留空间**：人物朝向的一侧留出画面；要入画的，首帧里先空着。
- **给字留位置**：要压字卡或片名的镜头，主体放在三分线一侧，另一侧留暗部、天空或虚焦。
- **同场景光线方向一致**：同一场戏的所有关键帧写同一个主光方向和色温。
- **景别跟分镜表**：关键帧的景别就是镜头的景别，不靠视频模型推拉去改景别。
- **点名肖像统一规格**：同一焦段、同一胸像景别、同一主光方向，背景虚化，每人一张。
- **匹配剪辑成对设计**：形状匹配的两个镜头（瞳孔→猫眼），两张图里主体的位置和大小对齐，出图后叠在一起检查。

## 按镜头类型选工具

| 镜头 | 工具 | 备注 |
|---|---|---|
| 冷开场大远景、空镜 | MJ | 人物很小时脸不重要，MJ 质感更好 |
| 主角近景/特写 | GPT-image-2（带设定卡） | 脸必须一致 |
| 对白正反打 | GPT-image-2 | 两人同场，参考两人设定卡 + 场景概念 |
| 怪物/反派局部 | MJ 出质感 → GPT-image-2 统一设计 | 先在设定卡里定好怪物设计 |
| 屏幕中的屏幕 | GPT-image-2 | 手机界面、紧急短信、报纸标题，写清每个字 |
| 母题插入（粒子、火、墨） | MJ，或直接让视频模型文生视频 | 不需要首帧也行 |
| 片名字形 | GPT-image-2 | 生成多版，挑一个矢量化 |
| 纹理底板 | MJ | 锈铁、宣纸、岩石、胶片颗粒 |

## 文件命名与清单

关键帧命名：`段落号_镜号_内容`，例如 `S3_042_对讲机流血.png`。换图用新后缀（`S3_042b_…`），不覆盖旧图。

素材清单 `_素材清单.csv` 列：

```
镜号,段落,资产类型,用途,工具,参考图,提示词,文件名,状态
042,S3 转折,关键帧,首帧,GPT-image-2,"角色卡_A.png;场景_楼道.png",见提示词文件#042,S3_042_对讲机流血.png,待出图
```

状态只用：待出图 / 已出图 / 已选定 / 需重做。
