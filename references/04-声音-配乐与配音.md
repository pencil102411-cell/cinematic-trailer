# 4 声音：配乐、音效、台词与旁白

预告片的声音分四层，分开做、分轨混：

| 层 | 内容 | 来源 |
|---|---|---|
| 音乐 | 一条完整的配乐，自带三幕起伏 | Suno 生成，剪到片长 |
| 预告片音效 | Braam、冲击、Boom、Riser、Whoosh、反向吸气、倒计时脉冲 | 音效库；少量可由视频模型生成 |
| 台词 / 旁白 | 对白（有口型）和画外旁白（无口型） | 视频模型原生对白、TTS 或真人录音 |
| 环境 / 动作声 | 风雨、脚步、打斗、火 | 视频模型生成的同期声 |

## 音乐的形状

实测响度曲线（`timeline.png`）几乎都是同一个形状：

1. **开场稀疏**：单音、钢琴、拨弦，中间留空白。剑来前 15 秒是"一个音—停—一个音"；模板第一张卡就是"一个单音配建立镜头"。
2. **逐步加层**：第二幕加入弦乐固定音型、打击乐，响度一级一级抬。
3. **中段落差**：一次明显的回落（剑来 107–112s、甜蜜家园 32s/69s），给第三幕起跑。
4. **高潮平台**：最后 25–30% 维持在最高响度，冲击密集。
5. **标题前 drop**：0.3–3 秒静音或只剩一句台词。
6. **片名砸**：冲击比前一刻高 12–18 dB（甜蜜家园 +15/+17/+12dB，奥本海默 +18/+14dB）。
7. **尾钩**：音乐关掉，只留环境声和一句台词，最后一个短促的 stinger。

节拍：铁证全程约 120 BPM；甜蜜家园高潮约 130 BPM（每 0.46s 一刀）；剑来点名段对应约 125 BPM 的八分音符（0.24s）；奥本海默靠越来越密的弦乐脉冲，不靠鼓点。

## Suno 配乐

### 做法

1. 按蓝图写一行"音乐形状"：每段的秒数和状态（稀疏/加层/回落/平台/drop/砸/尾钩）。
2. 用下面的风格提示词出 4–6 版，只听整体形状和高潮段，不指望它对齐画面。
3. 选一版后剪长度：在小节线上剪，删掉重复的段落，把最强的一段挪到 65–88% 的位置。用 `scripts/music_markers.py` 找小节和冲击。
4. Suno 的 Studio 里如果有分轨（stems）、延长（Extend）、局部替换（Replace Section），用它们修：比如把第一幕的鼓轨静音，让开场更空。功能和名字以用户界面上实际有的为准。
5. 标题砸、drop、Riser 这些点状设计不要指望 Suno 生成在准确位置，用音效层叠上去。

### 风格提示词（Style 栏，英文效果更稳）

纯器乐：打开 Instrumental。想用段落标签控制结构时，可以试着关掉 Instrumental，在歌词栏只写方括号标签、不写歌词；效果以实际生成为准。

| 题材 | Style |
|---|---|
| 好莱坞史诗 | `epic hybrid orchestral trailer score, sparse solo piano intro with long silences, deep brass braams, pulsing string ostinato build, taiko and big toms, synth risers, full choir climax, massive impacts, cinematic, instrumental` |
| 国风仙侠 | `epic chinese fantasy trailer score, solo guzheng and dizi intro, erhu melody, pipa tremolo, string ostinato build, taiko drums, full choir climax, wuxia cinematic, instrumental` |
| 犯罪刑侦 | `dark crime thriller trailer music, 120 bpm, ticking clock pulse, distorted sub bass, staccato strings, heavy hybrid percussion, sub drops, relentless build, aggressive climax, instrumental` |
| 惊悚恐怖 | `horror trailer music, detuned music box melody, eerie drones, dissonant string clusters, heartbeat pulse, sudden silences, metallic stingers, slow build to chaotic climax, instrumental` |
| 传记 / 剧情 | `minimalist tense orchestral trailer score, relentless accelerating violin ostinato, ticking pulse, low brass swells, solo piano motif, slow build, emotional climax, instrumental` |
| 慢版情绪歌 | `haunting slow cinematic ballad, solo female vocal, sparse piano, swelling strings, dark trailer arrangement` |

结构标签示例（歌词栏）：

```
[Intro: solo piano, single notes, long silences]
[Build: string ostinato enters, percussion grows]
[Break: sudden drop to near silence]
[Climax: full orchestra and choir, huge drums]
[Outro: one final massive hit, then silence]
```

版权提醒：不要让 Suno 翻唱真实存在的歌曲。要"经典老歌慢版翻唱"那种效果，就写原创旋律、复古风格。

## 预告片音效层

| 音效 | 时长 | 放在哪 |
|---|---|---|
| Braam（低音铜管轰鸣） | 2–4s | 转折、大视效、片名 |
| Hit / Impact（冲击） | 0.5–2s | 字卡、关键切点、黑场后第一帧 |
| Boom / Sub drop（低频下坠） | 1–3s | 黑场、静音前一刻 |
| Riser（上升音） | 2–8s | 段落高潮前；结束点对准冲击或静音的那一帧 |
| Whoosh（呼啸） | 0.3–1s | 快切、文字飞入、甩镜 |
| 反向吸气（reverse） | 0.5–1.5s | 冲击前，把耳朵吸进下一刀 |
| 脉冲 / 滴答 | 持续 | 倒计时、悬疑段 |
| Stinger | 0.5–1.5s | 尾钩最后一下 |
| 故障声 | 0.1–0.5s | 故障转场、屏幕画面 |

来源：Pixabay 音效、Freesound（注意每条的 CC 许可）、Sonniss 每年免费发布的 GDC 音效包；商用可买 BOOM Library、Soundly。视频模型生成的同期声适合环境和动作声，不适合做 Braam 和冲击。

## 台词与旁白

### 选台词

- 每句 ≤12 个汉字、2–3 秒内说完。长句拆开，中间放画面。
- 台词有三种功能，按顺序出现：**提问**（钩子，第一幕）→ **交代**（规则、赌注，第二幕）→ **宣言**（决心、主题，第三幕）。
- 第一、二幕密，第三幕稀。铁证只在前 13 秒有成段对白；奥本海默第三幕只剩宣言和倒数。
- 片名前最后一句 = 主题句。
- 排比最好用："见田野 / 见天地 / 见自由"每个词配一张脸。
- 问答对打：问句长、答句短（"你怎么知道的?"之前的答案只有一个词"十八"）。

### 放台词

- 一句台词盖 2–4 个镜头（L-cut），台词不必配说话人的脸。
- 每部片最多 1–2 句黑场台词。
- 台词之间留 0.3–1 秒给音乐和画面。
- 对白镜头里，台词尾音结束后留 4–8 帧再切。

### 旁白写法

第一人称内心独白（剑来、甜蜜家园开头）比第三人称解说更像预告片。短句、分行，每行一个意象：

```
开春了
天气也暖了
我想着
今年的日子能过得好一点
```

### 配音的来源

| 方式 | 适合 | 注意 |
|---|---|---|
| 视频模型原生对白（Seedance 2.5、MiniMax H3） | 有口型的对白镜头 | 同一角色每条都带同一段参考音频，声音才一致；H3 对白写成 `<d>[Chinese] 台词</d>` |
| TTS | 无口型的旁白、广播、电话 | 用户没指定工具时，可选本地 IndexTTS2、CosyVoice，或云端 MiniMax Speech、ElevenLabs；先问用户手上有哪个 |
| 真人录音 | 主旁白、关键台词 | 效果最好；录干声，后期加空间感 |

旁白要和对白在空间感上区分：旁白干、近、无混响；对白带场景混响。

## 混音

- 分轨：对白 / 旁白 / 音乐 / 预告片音效 / 环境，五条总线。
- 对白出现时音乐压低 6–10 dB（侧链或手动自动化），冲击层不压。
- 静音就是真静音，连环境声一起拿掉（实测静默点比周围低 28 dB 以上）。
- 网络平台成片：整体响度约 -14 LUFS，真峰值不超过 -1 dBTP，最后挂限制器。
- 在 DaVinci 的 Fairlight 页做；没有 DaVinci 时可用 ffmpeg `loudnorm` 做最后的响度归一（见 08）。
