# 2 镜头语言

## 预告片镜头的基本事实

- **一半左右是固定或微动镜头**（43–58%），但几乎没有完全死的画面：大多带缓慢推近或拉远（推 19–29%，拉 16–23%）。AI 生成时默认给"极慢推近"或"极慢漂移"，不要给大幅运镜，除非是动作镜头。
- **手持晃动集中在第三幕**。甜蜜家园手持占比从第一段 19% 升到第三段 33%；铁证集中在中段动作蒙太奇。抒情和对白段几乎不用手持。
- **一个镜头只讲一件事**。预告片里一个镜头平均只留 0.8–1.8 秒，观众只来得及读一个信息：一张脸的一个表情、一个动作的一个落点、一个物件。
- **景别跳着走**。连续两个镜头尽量不同景别（大远景→特写→中景），同景别连切会像跳帧。点名蒙太奇是例外，统一近景反而整齐。

## 每一幕的镜头配方

### 冷开场 / 第一幕：立世界

| 镜头 | 作用 | 样片 |
|---|---|---|
| 大远景，人物很小 | 世界的尺度和孤独感 | 甜蜜家园湖边背影；剑来石阶尽头的小人 |
| 逆光剪影 / 黄金时刻 | 气质和美 | 剑来开头连续 5 个逆光镜头 |
| 局部细节特写（手、脚、物件） | 不露脸先露处境，制造好奇 | 甜蜜家园窗台上的拖鞋；奥本海默引爆器的手 |
| 主角静态近景 | 让观众记住这张脸 | 剑来门廊下仰头的少年 |
| 生活流动作 | 日常，后面才有东西可失去 | 剑来过河、放风筝、烧火 |

运镜：固定或极慢推，镜头长 2–7 秒，叠化或黑场衔接。

### 第二幕：规则、赌注、升级

| 镜头 | 作用 | 样片 |
|---|---|---|
| 对话正反打（中近景） | 台词问答 | 奥本海默两人对坐，每镜 1.3–2.6s |
| 反应镜头 | 让观众跟着角色害怕 | 甜蜜家园主角惊恐大特写 |
| 屏幕中的屏幕 | 一个画面交代一条信息 | 手机 D-DAY、对讲机、紧急短信、电视讲话 |
| 群像 / 阵营 | 交代势力 | 铁证警队群像、反派团伙 |
| 威胁的局部 | 怪物或反派只给一部分 | 甜蜜家园怪物的手、牙；剑来巨爪 |
| 母题插入镜头 | 主题符号，兼做段落标点 | 奥本海默粒子、火焰、光波；剑来上帝视角俯拍 |

运镜：缓推为主，对话镜头稳定；升级段开始出现横移和手持。

### 第三幕：高潮

| 镜头 | 作用 | 样片 |
|---|---|---|
| 动作中段切入 | 只给最猛的那一下 | 铁证火场奔跑、枪口 |
| 眼睛 / 嘴 / 伤口大特写 | 情绪锚点，常放在片名前 | 甜蜜家园眼睛 1.8s；剑来血脸 7.4s |
| 奇观大远景 | 钱花在哪里，停得久一点 | 剑来法阵、奥本海默爆炸 |
| 肖像点名 | 群像戏的卡司展示 | 剑来 6 帧/3 帧一人 |
| 慢动作 | 在快切中间给一个可看清的瞬间 | 火星、雨滴、碎石 |

运镜：手持、快推、甩镜；第三幕里插一两个完全静止的镜头反而更有力。

## 招牌镜头类型

| 类型 | 怎么拍/生成 | 用在哪 |
|---|---|---|
| 上帝视角正俯拍 | 90° 垂直向下，人物在几何图形里（棋盘、八角井） | "命运被操控"类主题 |
| 形状匹配剪辑 | 两个镜头主体形状和位置相同（瞳孔→猫眼→井口） | 转场，尤其是惊悚 |
| 双重曝光 / 叠印 | 人脸叠火焰、叠星空，后期叠或直接生成 | 片名前的长停 |
| 抽象母题插入 | 粒子、火焰、光波、墨迹，0.3–1s | 段落标点、频闪蒙太奇 |
| 倒计时道具 | 楼层灯、钟表、倒数字 | 第三幕计数 |
| 鱼眼 / 超广角 | 怪诞、幽默 | 尾钩 |
| 剪影走向光源 | 人物在门/洞口逆光剪影 | 转折点、命运时刻 |
| 屏幕/镜面/玻璃后的人 | 隔着东西拍，交代处境 | 监控、对讲机、车窗 |

## 色彩弧线

每部片都有一个色彩主体系，并且随结构变化：

| 片 | 前 25% | 中段 | 高潮 | 读法 |
|---|---|---|---|---|
| 剑来 | 暖金（+3.4） | 冷青（-21） | 收尾暖金（+25） | 平凡日常 → 秘密与宿命 → 破局 |
| 甜蜜家园 | 冷（-4.3） | 中性 | 火与血的红（+34） | 日常 → 失控 |
| 铁证 | 冷蓝 | 暖橙（+25） | 蓝橙对撞 | 正（蓝）与邪（橙），字卡"正邪"也一蓝一橙 |
| 奥本海默 | 暖 | 彩色 + 黑白两条时间线 | 火焰橙 | 用黑白区分叙事线 |

（括号内是画面 R-B 均值，正数偏暖，负数偏冷。）

设计时给全片定：一个主色调、一个对比色、一条变化方向，写进蓝图，并在每条图像/视频提示词里写明这一镜的色温。

## 写进 AI 提示词的注意

- **生成长、使用短**。成片里 0.5–2s 的镜头，按 4–6s 生成，把动作峰值设计在 1.5–3s 之间，剪的时候取最好的一段。
- **首帧停在动作前一刻**。图像关键帧的构图要给动作留空间（人物朝向那边留出画面）。
- **方向连续**。追逐、对峙、视线方向按 180° 轴线规划，写进每条提示词（"人物朝画面左侧奔跑"）。
- **点名肖像统一规格**：同一焦段（85mm 左右）、同一景别（胸像）、主光方向一致、背景虚，每人一个微动作（抬眼、回头、嘴角一动），这样 6 帧一换才整齐。
- **字卡要留位置**。片名和字卡要压在画面上的镜头（空镜、背影），生成时把主体放在三分线一侧，另一侧留暗部或天空给字。
