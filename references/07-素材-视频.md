# 7 素材：视频（Seedance 2.5 / MiniMax H3）

## 开工前确认

两个模型的参数以用户实际使用的入口为准。开工前确认一次，写进蓝图：

| 项 | Seedance 2.5 | MiniMax H3（用户本地部署） |
|---|---|---|
| 单条时长 | 4–30s（用户其他 skill 里核实过的入口） | 4–15s，整数秒（官方模型卡） |
| 帧率 / 分辨率 | 以入口为准 | 24fps；默认短边 768。2K 可以再过一遍 H3-Regenerate-2K，但先拿 1–2 条和一采原片对比（二次精修实测过会让画面变脏） |
| 首尾帧 | 支持关键帧写法 | FL2VA 检查点：0 张图文生、1 张首帧或尾帧、2 张首尾帧 |
| 多参考 | 图 / 视频 / 音频多素材参考 | Ref2VA 检查点：最多 9 图 + 3 视频 + 3 音频（合计 ≤12）；首尾帧和参考素材不能混用 |
| 原生音频 | 有 | 有，32kHz 立体声；对白、音效、配乐分字段写 |
| 一条多镜头 | 支持，时间轴写切点 | 支持，`[Shot N]` 分段 + 时间戳 |

H3 的提示词写法以官方仓库的提示词指南为准（`docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md`、`..._ref_en.md` 和 `skills/` 目录）。H3 提示词可以交给 **minimax-h3-prompts**。

在用户电脑上真正提交生成（工作站地址、画布命令行）时，读 `references/本机工具链.md`（本机文件，不一定存在）。**提交只在用户明说"跑 / 生成 / 提交"时做。**

## 分工

| 用 Seedance 2.5 | 用 MiniMax H3 |
|---|---|
| 对白段（正反打一条生成，人物和声音一致） | 需要首尾帧精确控制的镜头：变形、匹配剪辑、入画出画 |
| 多镜头连续动作段落 | 批量单镜：点名肖像、空镜、母题插入（本地跑，适合多抽几次） |
| 需要很多参考素材的群像 | 需要 24fps 原生、后期统一帧率的镜头 |
| 长镜头动作（>15s） | 高潮里大量 4–5s 的短镜头 |

用户偏好的 Seedance 提示词体系在 **horizontal-cinematic-prompt-agent-v2** 里（五区块、精确焦段、时间轴）。写 Seedance 提示词时调用它，本 skill 提供每条的"预告片用途"：这一镜在成片里用几秒、取哪一段、动作峰值放在哪、和前后镜怎么接；同时带上人物锚点句、质感句和下面的避坑清单。

## 先判断：这一镜要不要生成视频（制作级别）

能用便宜、好控制的办法做，就不用 AI 视频。分镜表每一镜在"制作"列填一个级别，**只表示画面从哪来**；闪白、冲推这类叠在上面的效果写在"转场"列。

| 级别 | 画面从哪来 | 预告片里典型的镜头 | 用什么做 |
|---|---|---|---|
| **L1 剪辑 / 代码** | 不需要新画面，只对已有画面做效果或剪接 | 字卡、片名、黑场、闪白、频闪蒙太奇、口吃剪、故障、冲推、甩镜 | `animatic.py`、`title_card.py`、`fx.py`、DaVinci、AE |
| **L2 静图 + 代码运动** | 出一张图，用代码推拉、残影、闪切 | 点名蒙太奇的静态肖像、空镜慢推、屏幕中的屏幕、档案报纸、纹理底板 | MJ / GPT-image-2 出图 → `animatic.py` 缓推、`fx.py montage` |
| **L3 AI 视频** | 画面里有真实的动：人、物理现象、镜头在空间里穿行 | 对白、动作冲击、奇观运镜、物件慢动作、母题插入 | Seedance 2.5 / MiniMax H3 |
| **L4 视频编辑** | 在已有视频上改 | 修局部瑕疵、换背景、换机位、对口型 | video-local-edit、video-rephotography |

按顺序问：
0. 能从**已经要生成的某条 V 里截出来**？→ 标 L3，注明"复用 V 几"，不加生成量。
1. 只是效果、文字或剪接？→ L1。
2. 单独一张脸、一个物件、一个空镜，而且**画面里没有东西在真实地动**？→ L2（边界见 06"什么时候一张图就够"）。
3. 有人在动、有物理现象、镜头在空间里穿行？→ L3。
4. 已经有一段视频，要改？→ L4。

分镜表最后给一个**分级统计**：L1 几镜、L2 几镜（要出几张图）、L3 几镜（要生成几条 V）、L4 几镜。

## 规划生成单元

预告片镜头短（0.12–2s），生成下限是 4s，所以：

1. **生成长、使用短**。一条 4–6s 的生成，成片里只取 0.5–2s 的最佳段落。动作峰值写在第 1.5–3 秒，开头 0.5s 留给模型起势，剪掉。实测模型做动作常比提示词写的晚 0.5–1.5 秒，入点按实际找（见 10）。
2. **一条服务多个镜头**。同一条生成的不同时段可以剪成不同镜头：前段给第一幕的平静版，后段给第三幕的爆发版。
3. **多镜头一条只当草稿**：对白正反打、同场景连续动作写成一条多镜头，能省条数、保持一致。但**要卡拍、要对口型的正式素材，一条只拍一刀**：实测 H3 一条 30 秒排 12 个镜头，顺序被打乱，参考音频只跟了开头 2 秒（15 秒排 6 个镜头的几条是稳的）。Seedance 的多镜头先小测再批量用。
4. **点名肖像**：每个角色一条 4s 单镜，"胸像，极慢推近，一个微动作（抬眼/回头/嘴角一动），风吹发丝"，剪 6 帧或 3 帧用。只要 3–6 帧的，也可以直接用 L2 静图 + 残影（`fx.py montage --ghost`）。
5. **重要镜头多抽**：片名前长停、主角特写、高潮奇观，每条抽 3–4 次；普通镜头按下面跑法表。
6. **生成量估算**：一条 V 平均供给 1.5–3 个镜头。实际生成条数按计划的 **3–4 倍**估（小测、双种子、3–5 轮逐刀返修都算上），写进蓝图，别按多 30% 估。
7. **只用一采**：生成结果只用第一遍出的，别再叠精修和放大模型，除非小测证明更好（实测：二次精修让画面变脏、脸上出鳞片纹；SeedVR2 这类生成式放大让人变形）。

编号：生成条目用"V+三位数"（V001），在 `_视频提示词_vN.txt` 里写清每条对应哪些镜号、成片取哪一段。

### 一条只能有"四个一"

1. **一个机位起止**：从哪开始、停在哪。
2. **一个主运镜**，写成"起点 → 方向 → 终点 + 速度"（"从中景极慢匀速推到近景"），不能只写"推镜头"。
3. **一条连贯动作链**：最多 2–3 个连着发生、方向一致的小动作，每个写时间点（"第 1.5 秒回头，第 3 秒拔剑"）。
4. **一套光**：光源方向和颜色不变；要变光就拆两条，或后期做。

一条里写"先推近、再环绕、然后他拔剑冲出去、天色由暖变冷"＝必翻车。这是 AI 出废片的第一大原因。

## 跑法选择：什么镜头用什么方式生成

| 镜头 | 跑法 | 挂什么 | 种子 |
|---|---|---|---|
| 对白近景，要看嘴 | 参考生视频 + 参考音频（H3 Ref2VA；Seedance 多参考） | 设定卡 + 首帧图（目标景别）+ 这个角色的参考音频 | 2 个 |
| 有主角脸、不说话（回头、抬眼、走路、拔剑） | 参考生视频 | 设定卡 + 首帧图 | 1 个，动作难的 2 个 |
| 没有主角脸（手、脚、空镜、物件、远景人群） | 首帧生视频 | 首帧图 | 1 个 |
| 母题插入（粒子、火焰、墨迹） | 文生视频 | — | 1 个 |
| 有明确起止的空间变化（推穿、门开、后拉揭示、匹配剪辑） | 首尾帧 | 首帧 + 尾帧（尾帧不能比首帧多出人） | 1–2 个 |
| 多人同框（对峙、阵营群像） | 多参考生成 | 每人设定卡 + 空场景图 | 1 个；人多就降级：后排虚化、剪影、只让前排露脸 |
| 正顶俯拍有人 | 参考生视频 | 设定卡 + 一张已经从头顶拍到人的图当开场 | 2 个 |
| 已有视频换机位 | 视频编辑 / 换机位重拍 | 原视频 + 设定卡 + 场景图 | 1 个 |
| 画面里没东西真在动 | L2 静图 + 代码运动 | — | — |

首尾帧的坑：两张图差别很大时，模型常做成"溶解变形"（画面像融化一样从 A 变 B），不是镜头真的推进去。推穿要在提示词里写清"镜头向前推进穿过……"，生成后检查；不行就拆成两条，在遮挡帧硬切。

## 一致性：锚点句和质感句

1. **人物锚点句**：每个角色写一句固定的外貌描述（发型、脸上特征、上下装、配饰、专属细节），每条有这个角色的提示词**原样复用，一字不差**，别每次换说法。例：`沈青：束发白玉冠，左眉一道浅疤，月白交领长衫，深灰长裤，腰间青色剑穗`。同一角色有几套造型时，每套一句（`沈青·夜行装`），分镜表写清这一镜用哪套。
2. **质感句**：全片一句统一的画面描述，每条都带。例：`电影级打光，浅景深，低饱和暖金色调，35mm 镜头质感`。按蓝图色彩弧线分段的，每段一句。
3. **下装和配饰要写**：只给上半身参考又不写服装，模型每个种子会编一套不同的下装，还会丢掉发冠、帽子这类配饰。
4. **一场戏一套光**：同一场的所有条目，主光方向和色温写成一样。
5. **人物还没定稿**：锚点句先写占位（`[角色A：发型/服装待设定卡]`），并提醒用户先定人物——人物一变，关键帧和提示词全要改。

## 速度和复用交给剪辑

- **快推、猛甩、冲刺**：生成匀速版，后期加速 1.5–3 倍（`fx.py punch` 冲推、`fx.py whip` 甩镜）。写进分镜："【生成】匀速推进 5 秒 →【剪辑】第 2.5 秒起加速到 3 倍，落在冲击上"。
- **慢动作**：物件（火星、水滴、碎石）放心写"慢动作"。**有人物的慢动作要有说得出的理由**——实战里有人物的升格常被嫌"拖、看不懂"。没写速度时模型有时自己出慢动作，要写死"正常速度，不要慢动作"。
- **后期减速先补帧**（光流补帧），不然一卡一卡。
- **一条素材多用**：倒放（后拉揭示倒放就是推进）；裁掉一圈放大 1.2–1.3 倍做"假推近"（再大就糊，要真特写单独生成）；只取 2–6 帧给闪切、口吃剪；同机位的几条接成一个长镜头。

## 预告片专用镜头配方

下面是"写什么"，具体句式按所用模型的写法套。

| 镜头 | 要点 |
|---|---|
| 冷开场空镜 | 固定或极慢推；只写一个环境运动（雾流、光移、尘浮）；"画面安静" |
| 主角肖像 / 点名 | 胸像、85mm 浅景深、极慢推近、一个微动作、主光方向固定 |
| 对白正反打 | 写清谁说哪句、说话时的表情变化；镜头稳定；台词照分镜表原文 |
| 屏幕中的屏幕 | 屏幕内容由首帧决定；只写屏幕光在脸上闪、手指滑动 |
| 威胁局部 | 只露局部（手、牙、影子），主体在画面边缘出入，浅景深 |
| 动作冲击 | 写清动作起止和落点；手持晃动；落点放在第 2–3 秒；写"正常速度" |
| 慢动作瞬间 | 火星、水滴、碎石、发丝；写"慢动作，看清每一粒"；有人物的要有理由 |
| 奇观大远景 | 摄影机慢推或慢升；比例参照物（小人影）；停留时间长 |
| 母题插入 | 文生视频即可：粒子、火焰漩涡、光波、墨迹晕开，纯黑背景便于叠加 |
| 片名背景板 | 纹理或粒子缓慢流动、无主体、无文字，留中心给片名 |
| 尾钩 | 一个完整的小动作（开后备箱、门缝一闪），节奏比前面慢 |

## 避坑清单（写完每条提示词对一遍）

| 别这样写 | 会发生什么 | 改成 |
|---|---|---|
| 近景里写地面、脚下的东西 | 为了拍到地面，拉成全身远景 | 不写画面外的东西；加"第一帧看不到地面，镜头不拉远" |
| "全身" | 拉得太远，人变小、脸变形 | 写到膝盖 / 到腰；要全身就单独一镜 |
| "看不清面部""面部隐在阴影里" | 脸被糊掉 | 写光从哪来、哪半边脸暗，不写"看不清" |
| 群众只写"围观的人群" | 群众死盯镜头、一动不动 | 写群众在干什么、看哪里（"交头接耳，看向画左的火光，不看镜头"） |
| 只写"两人往前走" | 倒着走、走反方向 | 写脸朝哪、往哪走、离镜头近了还是远了，和 180° 轴线对上 |
| 人和道具的精细互动（一脚踢倒柱子、手推开门） | 人没做动作，东西自己倒了 | 互动放远景或虚化；或改成东西自己动、人不碰 |
| 首尾帧：尾帧有人、首帧没人 | 人凭空浮现 | 首帧里就有剪影（门缝里、远处） |
| 不写速度 | 有时自动出慢动作 | 写"正常速度，不要慢动作" |
| 首帧图、场景图里有字（招牌、门牌） | 视频里长出乱码字 | 出图时就擦掉；提示词写"不出现文字"作用有限（实测 H3 不太听） |
| 该暗的灯在首帧图里亮着 | 提示词写"灯全灭"也压不住 | 首帧图本身就是灭灯的 |
| 多参考生成只写站位和构图，不写动势 | 人全部站桩，像静图 | 每个人写在做什么、往哪动，镜头怎么动 |
| 一条里写好几个镜头、好几个场景 | 顺序乱、背景跳 | 一条一刀（"四个一"） |
| 对白近景写"嘴自然闭合" | 该说话的不说 | 要说就写台词、带参考音频；不说才写闭嘴 |

## 音频怎么写

- 配乐后期统一用 Suno，**每条都写"不要背景音乐"**（H3 的 `non_diegetic_music` 写 none）。
- 对白镜头：写准台词原文和语言，带同一角色的参考音频，保持声线。
- 非对白镜头：只要环境和动作音效；寂静镜头写"几乎无声"。
- 画面里删掉的东西，声音里也删掉。
- 模型仍然带出音乐的条目，后期只用画面。

## 生成回来以后

怎么看、怎么挑种子、从第几秒用、怎么按镜号逐刀改，见 **10-生成以后.md**。快速检查：脸是否一致、手指和肢体、画面里有没有乱码文字、物理（水往上流、火倒着烧）、首帧跳变、方向是否和分镜一致。只坏一小段的，优先用 **video-local-edit** 局部修，不整条重跑。
