# 7 素材：视频（Seedance 2.5 / MiniMax H3）

## 开工前确认

两个模型的参数以用户实际使用的入口为准。开工前确认一次，写进蓝图：

| 项 | Seedance 2.5 | MiniMax H3（用户本地部署） |
|---|---|---|
| 单条时长 | 4–30s（用户其他 skill 里核实过的入口） | 4–15s，整数秒（官方模型卡） |
| 帧率 / 分辨率 | 以入口为准 | 24fps；默认短边 768，2K 需要再过一遍 H3-Regenerate-2K |
| 首尾帧 | 支持关键帧写法 | FL2VA 检查点：0 张图文生、1 张首帧或尾帧、2 张首尾帧 |
| 多参考 | 图 / 视频 / 音频多素材参考 | Ref2VA 检查点：最多 9 图 + 3 视频 + 3 音频（合计 ≤12）；首尾帧和参考素材不能混用 |
| 原生音频 | 有 | 有，32kHz 立体声；对白、音效、配乐分字段写 |
| 一条多镜头 | 支持，时间轴写切点 | 支持，`[Shot N]` 分段 + 时间戳 |

H3 的提示词写法以官方仓库的提示词指南为准（`docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md`、`..._ref_en.md` 和 `skills/` 目录）。

## 分工

| 用 Seedance 2.5 | 用 MiniMax H3 |
|---|---|
| 对白段（正反打一条生成，人物和声音一致） | 需要首尾帧精确控制的镜头：变形、匹配剪辑、入画出画 |
| 多镜头连续动作段落 | 批量单镜：点名肖像、空镜、母题插入（本地跑，适合多抽几次） |
| 需要很多参考素材的群像 | 需要 24fps 原生、后期统一帧率的镜头 |
| 长镜头动作（>15s） | 高潮里大量 4–5s 的短镜头 |

用户偏好的 Seedance 提示词体系在 **horizontal-cinematic-prompt-agent-v2** 里（五区块、精确焦段、时间轴）。写 Seedance 提示词时调用它，本 skill 提供每条的"预告片用途"：这一镜在成片里用几秒、取哪一段、动作峰值放在哪、和前后镜怎么接。

## 规划生成单元

预告片镜头短（0.12–2s），生成下限是 4s，所以：

1. **生成长、使用短**。一条 4–6s 的生成，成片里只取 0.5–2s 的最佳段落。动作峰值写在第 1.5–3 秒，开头 0.5s 留给模型起势，剪掉。
2. **一条服务多个镜头**。同一条生成的不同时段可以剪成不同镜头：前段给第一幕的平静版，后段给第三幕的爆发版。
3. **多镜头一条**：对白正反打、同场景连续动作，写成一条多镜头，减少条数、保持一致。
4. **点名肖像**：每个角色一条 4s 单镜，"胸像，极慢推近，一个微动作（抬眼/回头/嘴角一动），风吹发丝"，剪 6 帧或 3 帧用。
5. **重要镜头多抽**：片名前长停、主角特写、高潮奇观，每条抽 3–4 次；普通镜头 1–2 次。

编号：生成条目用"V+三位数"（V001），在 `_视频提示词_vN.txt` 里写清每条对应哪些镜号、成片取哪一段。

## 预告片专用镜头配方

下面是"写什么"，具体句式按所用模型的写法套。

| 镜头 | 要点 |
|---|---|
| 冷开场空镜 | 固定或极慢推；只写一个环境运动（雾流、光移、尘浮）；"画面安静" |
| 主角肖像 / 点名 | 胸像、85mm 浅景深、极慢推近、一个微动作、主光方向固定 |
| 对白正反打 | 写清谁说哪句、说话时的表情变化；镜头稳定；台词照分镜表原文 |
| 屏幕中的屏幕 | 屏幕内容由首帧决定；只写屏幕光在脸上闪、手指滑动 |
| 威胁局部 | 只露局部（手、牙、影子），主体在画面边缘出入，浅景深 |
| 动作冲击 | 写清动作起止和落点；手持晃动；落点放在第 2–3 秒 |
| 慢动作瞬间 | 火星、水滴、碎石、发丝；写"慢动作，看清每一粒" |
| 奇观大远景 | 摄影机慢推或慢升；比例参照物（小人影）；停留时间长 |
| 母题插入 | 文生视频即可：粒子、火焰漩涡、光波、墨迹晕开，纯黑背景便于叠加 |
| 片名背景板 | 纹理或粒子缓慢流动、无主体、无文字，留中心给片名 |
| 尾钩 | 一个完整的小动作（开后备箱、门缝一闪），节奏比前面慢 |

## 音频怎么写

- 配乐后期统一用 Suno，**每条都写"不要背景音乐"**（H3 的 `non_diegetic_music` 写 none）。
- 对白镜头：写准台词原文和语言，带同一角色的参考音频，保持声线。
- 非对白镜头：只要环境和动作音效；寂静镜头写"几乎无声"。
- 画面里删掉的东西，声音里也删掉。
- 模型仍然带出音乐的条目，后期只用画面。

## 质检

每条生成回来检查：脸是否一致、手指和肢体、画面里有没有乱码文字、物理（水往上流、火倒着烧）、首帧跳变、方向是否和分镜一致。不合格的标"需重跑"并写原因。只坏一小段的，优先用 **video-local-edit** 局部修，不整条重跑。
