# 3 切点与转场

## 先定声音，再切画面

预告片是"给声音配画面"。顺序固定：

1. 音乐选定并剪好长度（见 04）。
2. 台词和旁白按蓝图放上时间线。
3. 用 `scripts/music_markers.py` 打出拍点、小节、冲击、静音点。
4. 画面最后上，按下面三类切点去切。

## 三类切点

| 类型 | 规则 | 用在 | 实测 |
|---|---|---|---|
| **卡拍** | 切点落在强拍或冲击的同一帧，最多提前 1 帧（视觉比听觉慢一点，提前 1 帧看起来更准） | 字卡、片名、冲击镜头、点名蒙太奇、倒计时 | 铁证"自古/正邪/不两立"落在 71.00/72.00/73.00；片名 75.50 对起音 75.51 |
| **跟台词** | 台词说完留 4–8 帧再切；或让台词越过切点继续（L-cut），一句台词盖 2–4 个镜头 | 对白段、旁白段 | 铁证开场每句台词盖 2–3 个镜头；甜蜜家园总统讲话盖 4 个镜头 |
| **动作切** | 在动作中段切，下一镜从动作结果开始；动作落点砸在冲击上 | 打斗、奔跑、爆炸 | 甜蜜家园 127.2s 冲击 +15dB 同帧切 |

不是每刀都卡。实测切点落在声音起音上的比例是 35–45%（随机 23–27%）。主要的刀卡在强拍，其余落在台词和动作上，或者故意错开半拍，节奏才不机械。

## 帧数速查

| 帧数 @24fps | 秒 | 用途 |
|---|---|---|
| 1–3 | 0.04–0.125 | 闪白、频闪、极速点名（剑来 3 帧一人@25fps） |
| 6 | 0.25 | 点名蒙太奇、口吃剪碎片 |
| 10–12 | 0.42–0.5 | 拆句字卡、倒计时一拍（120–130 BPM 的一拍） |
| 18–24 | 0.75–1 | 第三幕普通镜头 |
| 36–60 | 1.5–2.5 | 第二幕对白、片名前特写 |
| 72–170 | 3–7 | 开场建立、片名前的长停、尾钩 |

BPM 换算：一拍秒数 = 60 / BPM。120 BPM 一拍 0.5s（12 帧@24fps），八分音符 0.25s，十六分 0.125s。

**加速公式**：第三幕每一段把镜头长减半——1s → 0.5s → 0.25s → 0.12s，每段 4–12 刀，段与段之间插一个 1–1.5s 的大镜头换气（剑来 0.24s ×11 → 1.2s 法术 → 0.24s ×10 → 0.12s ×9）。

## 转场库

硬切占绝大多数。其他转场都是"标点"，用得越少越有力。

| 转场 | 参数 | 用在 | 样片 |
|---|---|---|---|
| 硬切 | — | 默认 | 全部 |
| 黑场渐显 / 渐隐 | 12–24 帧；黑场停 0.5–2.7s | 开场、幕间、片名前 | 甜蜜家园开头；奥本海默 147s 黑场 2.7s |
| 黑场间隔 | 镜头 0.5–0.8s + 黑 0.2–0.7s 交替，3–8 组 | 压抑、审判、回忆 | 奥本海默 154–163s 黑白听证会 |
| 闪白 | 短闪 1–6 帧；过曝过渡 14–55 帧 | 冲击、爆炸、枪口、片名 | 奥本海默 3 帧闪白接爆炸；剑来 6 帧 |
| 频闪蒙太奇 | 画面 0.2–0.33s 与黑场交替，配一个大冲击 | 第二幕结尾的爆发 | 奥本海默 104–106s |
| 叠化 | 12–80 帧 | 抒情序章、时间流逝、回忆 | 剑来水下→悬崖→脸 |
| 故障 / 信号干扰 | 2–8 帧 RGB 分离 + 横纹 | 屏幕、监控、惊悚、科技 | 甜蜜家园对讲机画面 |
| 口吃剪 | 同一镜头切成 3–8 帧碎片重复，每片微跳 | 心理崩溃、关键动作强调 | 铁证女人侧脸、手抓栏杆 |
| 字卡插切 | 镜头—字卡—镜头，字卡落在拍上 | 拆句标语、章节卡 | 甜蜜家园、铁证 |
| 形状匹配 | 两镜主体形状/位置一致 | 惊悚、奇幻转场 | 甜蜜家园眼睛→猫眼 |
| 叠印 | 两层画面叠 2–8s | 片名前长停 | 奥本海默人脸叠火焰 8.4s |
| 平台擦除 | 品牌色条纹擦除 | 只用于落版平台卡 | Netflix 红色条纹 |

### 声音转场

- **J-cut**：下一场的声音提前 4–12 帧进来，画面后到。最常用的进场方式。
- **L-cut**：这一句台词越过切点，盖到下一个画面上。
- **黑场台词**：画面全黑，只有一句台词（"我是感染者"）。比任何画面都抓人，一支片最多用 1–2 次。
- **反向吸气（reverse / suck-back）**：冲击前 0.5–1.5s 的反向混响或反向镲片，把耳朵"吸"进下一刀。

## 呼吸与长停

快切中间必须有长停，否则观众会疲劳、也感觉不到快：

- 片名前给一个 2–8s 的长停（甜蜜家园 6.7s 主角、奥本海默 6.5s 和 8.4s、剑来 7.4s）。
- 第二幕和第三幕之间给一次 1–3s 的黑场或静音。
- 长停镜头内部要有变化：极慢推近、焦点转移、叠印逐渐显影、表情慢慢变。

## 剪辑检查

- 每个字卡、片名、大冲击都和拍点同帧（±1 帧）。
- 连续两个镜头不同景别；同一角色的视线、运动方向一致。
- 台词没有被硬切掐掉尾音（留 4–8 帧）。
- 第三幕整体加速，中间有 1–2 次换气。
- 片名前有 drop，片名后有尾钩。
- 不用软件自带的花哨转场（翻页、旋转、缩放转场）。
