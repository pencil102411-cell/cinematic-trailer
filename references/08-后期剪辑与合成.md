# 8 后期：剪辑、合成、调色、混音、导出

## 总顺序

```
分镜表 + 占位卡 + 临时音乐 → animatic v1（看节奏）
   ↓ Suno 定稿 + music_markers.py 打点 → 按拍改时长 → animatic v2
   ↓ 关键帧出图 → animatic v3（图片缓推）
   ↓ 视频生成回来 → 填"素材/入点" → animatic v4 = 粗剪（带同期声）
   ↓ DaVinci 精剪：替换字卡为 AE/Remotion 成品、加音效层、旁白、调色、混音
   ↓ 导出成片 + 无字幕版 + SRT
```

每一版 animatic 都完整看三遍：第一遍只听声音，第二遍只看画面，第三遍看整体。问题写进分镜表的"备注"列，再出下一版。

## 两条路线

| 路线 | 适合 | 工具 |
|---|---|---|
| 脚本路线 | 快速出 animatic、粗剪，或简单成片 | `animatic.py` + `title_card.py` + ffmpeg |
| 剪辑软件路线 | 正式成片 | DaVinci Resolve 剪辑/调色/混音，AE 或 Remotion 做字卡，Blender 做 3D 片名 |

两条路线共用同一份分镜表。`animatic.py` 每次输出的 `_剪辑表.csv` 有每镜的入点/出点时间码，在 DaVinci 里照着搭时间线，或者把 animatic 成片放在最上面一轨当参考对位。

## DaVinci Resolve

### 工程

- 时间线 24fps（和样片、MiniMax H3 一致），1920×1080 或 3840×2160。帧率开工时定死，中途不改。
- 媒体池分箱：视频素材 / 关键帧 / 字卡 / 音乐 / 预告片音效 / 对白 / 旁白 / 参考。

### 轨道布局

| 轨 | 内容 |
|---|---|
| V1 | 主画面 |
| V2 | 字卡、片名（ProRes 4444 透明） |
| V3 | 闪白、黑场、叠印、调整层（统一调色、颗粒） |
| V4 | animatic 参考（关闭显示） |
| A1 / A2 | 对白 / 旁白 |
| A3 | 音乐（Suno，可分 stems 多轨） |
| A4–A6 | 预告片音效：冲击、Braam、Riser/Whoosh |
| A7 | 环境、动作同期声 |

### 导入标记和字幕

- `music_markers.py` 生成的 `resolve_markers.edl`：时间线 → 导入 → 时间线标记（EDL）。时间线起始时间码默认 01:00:00:00，不一样就在脚本里用 `--start-tc` 改。作者环境没有装 Resolve，第一次用时先拿几个标记核对位置。
- `animatic.py` 生成的 `.srt`：文件 → 导入 → 字幕，落到字幕轨，再统一改样式（见 05）。

### 剪辑手感

- 切点用标记吸附（快捷键 N 开关吸附）。
- 关键刀提前 1 帧（视觉比听觉慢）。
- 对白镜头用 L-cut：在时间线上把音频出点拖过视频出点。
- 闪白：V3 放 1–6 帧白色固态，合成模式"相加"，透明度关键帧衰减。
- 黑场间隔：直接在 V1 留空隙。

### 调色：把 AI 素材统一成一部片

AI 生成的镜头曝光、白平衡、颗粒各不相同，必须统一：

1. **逐镜校正**（节点 1）：曝光、白平衡、对比，把每个镜头拉到同一基准。
2. **统一风格**（时间线调整层或组）：全片色调。按蓝图的色彩弧线，分段做 2–3 个版本（如序章暖金、悬疑冷青、高潮暖红）。
3. **颗粒和柔化**：加一层胶片颗粒，能遮掉 AI 画面的塑料感和细小瑕疵。
4. **宽银幕遮幅**：时间线 → 输出遮幅 → 2.39。
5. 闪烁、超分等功能（Deflicker、Super Scale 等）部分只在 Studio 版有，以用户的版本为准。

### 混音（Fairlight）

- 建五条总线：对白、旁白、音乐、音效、环境。
- 音乐总线挂压缩器，侧链接对白总线，对白时压 6–10 dB。
- 静默点所有总线一起拉到底，包括环境。
- 主输出挂限制器，响度表看整体 -14 LUFS、真峰值 ≤ -1 dBTP。

### 导出

| 用途 | 格式 |
|---|---|
| 网络成片（B 站、视频号、YouTube） | H.264 或 H.265，24fps，1080p 码率 ≥ 10 Mbps，4K ≥ 35 Mbps；AAC 320k、48kHz |
| 母版 | ProRes 422 HQ，PCM 音频 |
| 无字幕版 | 同上，关闭字幕轨和对白字卡 |
| 字幕 | SRT 单独导出 |

## After Effects

- 每张字卡一个合成，24fps，和时间线同尺寸；合成时长 = 分镜表时长 + 前后各 12 帧余量。
- 运行 `music_markers.py` 生成的 `ae_markers.jsx`（文件 → 脚本 → 运行脚本文件），合成里会多出两个带标记的空对象层：MUSIC_BEATS（每拍）和 MUSIC_MARKERS（小节、冲击、静音）。字卡的冲击帧对齐标记。作者环境没有装 AE，第一次用时先检查标记位置。
- 动效配方见 05。
- 导出 ProRes 4444 + Alpha（RGB + Alpha，直通），放到 DaVinci 的 V2。

## Remotion

适合把一整套字卡（章节卡、拆句卡、演职员表、字幕）写成组件，改一处全片统一。组件示例和透明导出命令见 05。`music_markers.py` 的 `markers.json` 可以直接读进来，把字卡入点对到拍上。需要 Node 18+。

## Blender

3D 片名、金属/石刻字、粒子聚散、logo 演绎。渲染 RGBA PNG 序列（24fps），在 DaVinci/AE 里叠加。

## 素材规格统一

- **帧率**：全部转到 24fps。不是 24fps 的生成结果，在 DaVinci 里按时间线帧率重定时，或 `ffmpeg -i in.mp4 -vf fps=24 out.mp4`。
- **分辨率**：MiniMax H3 默认短边 768，正式成片前用 H3-Regenerate-2K 过一遍，或者超分（Topaz Video AI、Resolve Studio 的 Super Scale）。
- **画幅**：所有生成都按 16:9；要 2.39 就在剪辑时加遮幅，不要直接生成 2.39 的画面再拉伸。

## 只用脚本出成片

不开剪辑软件时：

```bash
python animatic.py 分镜表.csv --out 成片_无混音.mp4 --music 配乐.wav --clip-audio --burn-subs --scope
ffmpeg -i 成片_无混音.mp4 -c:v copy -af loudnorm=I=-14:TP=-1:LRA=11 -c:a aac -b:a 320k 成片.mp4
```

`animatic.py` 的混音只是"同期声 + 配乐"简单相加，没有压限和侧链，预告片音效层也要事先混进配乐里。正式成片还是建议进 DaVinci。
