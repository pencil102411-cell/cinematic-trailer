# 9 样片拆解

本 skill 的规律来自对 5 部预告片的逐帧分析（2026-11）。每一帧都算了亮度、色彩差、光流（平移/缩放/抖动），据此检测硬切、黑场、闪白、叠化；音频算了响度曲线、低频冲击、起音点、静音断点和节拍；台词用 Whisper 转写对时；每个镜头抽首/中/尾帧人工看过。

> 数字是机器检测结果。叠化会被算成一个长镜头（《剑来》的抒情段尤其明显），黑场/字卡段也计入镜头数，所以 ASL 只作量级参考。新的参考片可以用 `scripts/analyze_trailer.py` 自己跑。

| 时间 | 段落 | 内容与手法 |

| 62–75 | 高潮 | 镜头 0.4–0.9s；拆句字卡 **"自古 / 正邪 / 不两立"** 各 0.43s，精确落在 71.00、72.00、73.00 三个强拍上；"正邪"二字一蓝一橙 |

| 77–83 | 尾钩 | 音乐 80.7s 起完全静音 2.3s；鱼眼镜头里两人开后备箱的轻松一幕，叠"敬请期待 COMING SOON" |
| 83–86 | 落版 | 平台 + 出品方 |

## 大片预告模板（Gaiamount 中字版，136s）

一支把好莱坞预告片套路写成文字卡的模板，每张卡说明"这里该放什么"，配乐和台词按真实节奏走。按时间（占全片比例）：

| 位置 | 该放什么 |
|---|---|
| 0–7% | 一个单音配建立镜头；再一个单音配更多建立镜头 |
| 7–10% | 一声低沉 Braam，接一句故作深沉的话或问题 |
| 10–18% | 旁白提问 → 用意想不到的揭示收尾（"其实那件事是真的"） |
| 19% | 厂牌卡 |
| 20–27% | 引入一首经典歌曲的意外慢版翻唱 |
| 28–31% | 大视效镜头 + Braam，接坏消息（"它会毁灭一切"） |
| 33–38% | 增加音乐层次，接号召行动（"要有人阻止这件事"） |
| 38–43% | 主角们看起来充满希望的镜头（"那个人就是你"） |
| 43–47% | 单个镜头；反派或灾难的镜头（"你不会以为事情这么简单吧?"） |
| 47–50% | 快切，音乐铺垫 |
| 51% | 档期卡（明年暑期……） |
| 53–55% | 用现有视效镜头剪蒙太奇；"有远见的导演"资历卡 |
| 56–62% | 翻唱编曲更自信、几乎带反叛感；用剩下的视效继续抬高赌注 |
| 60–65% | 以怀疑主角命运的场景结束这段（"我不是天选之人""你是"） |
| 66–70% | 轻 whoosh → 重 whoosh → 弦乐 cluster 上升 → 合唱 cluster 上升 |
| 71–73% | 演员卡（几个演员，加 B 咖、A 咖） |
| 73–76% | 翻唱到高潮，快速轮换主角英雄镜头 |
| 77–82% | 一句关于因果或宿命的宣言（多半来自反派） |
| 82–86% | 加长的视效烧钱镜头，停得稍微有点太长 |
| 86–88% | 把前面那句宣言说完 |
| 88–90% | 片名 + 最后一声 Braam |
| 91–93% | 具体上映日期 + 话题标签 |
| 93–95% | 演职员 billing，出现时间刚够看到、不够读完 |
| 95–100% | 厂牌 |

它和四部实片对得上：单音开场（剑来）、资历卡（甜蜜家园、奥本海默、剑来）、档期卡前置（甜蜜家园）、演员快速轮换（剑来）、宿命宣言 + 停太长的奇观（剑来 7.4s 血脸、奥本海默 8.4s 叠印）、片名砸 Braam（四部都有）。
