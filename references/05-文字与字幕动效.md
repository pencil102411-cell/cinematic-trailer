# 5 文字卡与字幕动效

## 文字卡清单

| 卡 | 位置 | 时长 | 样式 | 样片 |
|---|---|---|---|---|
| 厂牌 / 出品方 | 最前，或冷开场之后 | 每个 1–3s | 官方 logo 动画 | 奥本海默两个厂牌共 8s；甜蜜家园把平台标放在冷开场后 |
| 资历卡 | 第二幕中段 | 2–4s | 黑底白字，或动态背景 | "《鬼怪》导演 李应福"2.2s；"导演 克里斯托弗·诺兰"3.7s |
| 档期卡（先导） | 25–50% | 0.9–2s | 黑底极简 | 甜蜜家园"12月18日"在 28% 处 |
| 章节词卡 | 群像段 | 0.5–2.3s | 大号英文 + 小号中文，字母内填画面 | 铁证 JUSTICE 正义 / VILLAINY 邪恶 / CLASH 交锋 / SHOWDOWN |
| 拆句标语卡 | 第三幕 | 每张 0.4–1s，落拍 | 一句话拆 2–4 张，与镜头交替 | "准备好/面对/内心的恐惧"；"自古/正邪/不两立" |
| 片名 | 88–92% | 2–6s | 全片最重的设计 | 锈铁、粗糙颗粒+红叉、书法+金丝带、极简白字 |
| 尾钩叠字 | 尾钩镜头上 | 3–6s | 两侧分列，半透明 | 铁证"敬请 / 期待 COMING SOON" |
| 落版 | 最后 | 2–4s | 平台、日期、出品方、billing | 全部 |

规则：
- 字卡尽量落在拍上（见 03），淡入不超过 6–8 帧，否则会拖拍。
- 拆句卡用同一种版式，只换字；卡与卡之间至少夹一个镜头。
- 片名前不要再出别的字卡；片名后到落版之间只能有尾钩。

## 版式参数（1080p）

| 元素 | 字号（占画高） | 说明 |
|---|---|---|
| 片名 | 15–25% | 居中或居中略上；英文副标题 25–35% 片名大小，字距拉开 |
| 字卡主字 | 6–10% | 中文字间加空格或字距（"準 備 好"） |
| 章节卡英文 | 40–60% | 全大写窄体，内填画面纹理 |
| 资历卡 | 主行 4–5%，作品名 3% | 作品名在上，人名在下 |
| 对白字幕 | 3.3–4%（约 36–44px） | 底部居中，离底边 7–9% |
| 英文字幕 | 中文的 70% | 中文在上、英文在下（剑来） |

对白字幕：白字 + 细黑描边或柔和阴影，不加底条；一条一句；显示到台词结束后 4–6 帧；可以跨切点；不压在字卡和片名上。字幕和画面里的文字冲突时，挪字幕不挪画面。

字体：国风片名用书法（找书法家写或 GPT-image-2 生成字形再矢量化），现代犯罪用粗黑窄体，惊悚用粗糙手写/做旧，传记用极简无衬线。免费可商用：思源黑体、思源宋体、站酷高端黑、阿里巴巴普惠体、Bebas Neue、Oswald。方正、汉仪等商用字体需要授权，交付前提醒用户。

## 动效配方

每种都给 AE 做法；能代码化的给 Remotion；`scripts/title_card.py` 能直接渲染前五种做预览或简单成片。

| 动效 | 何时用 | AE 做法 |
|---|---|---|
| **推近淡入** fade | 资历卡、档期卡、静的字卡 | 不透明度 0→100（0–8 帧）；缩放 100→106%（整段）；文字动画器"字符间距"20→60 |
| **砸入** slam | 片名、拆句卡、章节卡 | 缩放 135%→100%（0–4 帧，缓出）+ 运动模糊；第 4 帧白色固态层"相加"不透明度 70→0（4–7 帧）；位置表达式 `wiggle(30, 25*Math.max(0,1-(time-inPoint)/0.4))` 做衰减抖动；加发光 |
| **光扫** sweep | 金属、石刻片名 | 复制文字层，效果 > 生成 > CC Light Sweep，中心从左到右走 1–1.5s |
| **故障** glitch | 科技、惊悚、屏幕相关 | Shift Channels 做 RGB 错位 + 置换图（分形杂色）横向撕裂，只开 2–6 帧 |
| **双色** split | 对立主题："正邪" | 两个字分两层，各自上色（冷蓝 / 暖橙）加同色发光 |
| 纹理填充 / 镂空 | 章节卡（铁证） | 文字层做素材层的 Alpha 遮罩（轨道遮罩） |
| 书法写出 | 国风片名 | 文字转形状 → 修剪路径；或描边效果"在透明背景上绘画"；也可让视频模型生成"墨迹笔画写出"素材，用"滤色"叠上 |
| 粒子聚散 | 仙侠、奇幻片名 | Trapcode Particular / Form（付费）；内置可用 CC Particle World；或 Blender |
| 3D 金属/石刻 | 史诗、犯罪片名 | AE 的 Cinema 4D 渲染器挤出，或 Blender |
| 楼层灯 / 倒数字 | 倒计时高潮 | 点阵字体 + 发光，每拍换一个数 |

### Remotion（代码化字卡）

适合批量出风格统一的字卡和字幕。下面是"砸入"的组件写法（需要 Node 18+；本机未装 Node，这段没有实际跑过，第一次用时先渲一帧检查）：

```tsx
import {AbsoluteFill, Easing, interpolate, useCurrentFrame, useVideoConfig} from 'remotion';

export const SlamTitle: React.FC<{text: string; sub?: string}> = ({text, sub}) => {
  const f = useCurrentFrame();
  const {durationInFrames: d} = useVideoConfig();
  const clamp = {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'} as const;
  const scale = interpolate(f, [0, 4], [1.35, 1], {...clamp, easing: Easing.out(Easing.cubic)})
    + interpolate(f, [4, d], [0, 0.04], clamp);
  const blur = interpolate(f, [0, 4], [12, 0], clamp);
  const flash = interpolate(f, [3, 4, 7], [0, 0.7, 0], clamp);
  const shake = f < 12 ? Math.sin(f * 2.7) * (12 - f) * 1.2 : 0;
  const fadeOut = interpolate(f, [d - 6, d], [1, 0], clamp);
  return (
    <AbsoluteFill style={{justifyContent: 'center', alignItems: 'center', opacity: fadeOut}}>
      <div style={{transform: `translate(${shake}px, ${shake * 0.4}px) scale(${scale})`,
        filter: `blur(${blur}px)`, color: 'white', fontSize: 220, letterSpacing: '0.08em',
        fontFamily: 'Source Han Sans SC', fontWeight: 900, textShadow: '0 0 30px rgba(255,255,255,.35)'}}>
        {text}
      </div>
      {sub && <div style={{color: 'white', fontSize: 48, letterSpacing: '0.6em', marginTop: 24}}>{sub}</div>}
      <AbsoluteFill style={{backgroundColor: 'white', opacity: flash}} />
    </AbsoluteFill>
  );
};
```

带透明通道导出（给 DaVinci/AE 叠加用）：

```bash
npx remotion render SlamTitle out/title.mov --codec=prores --prores-profile=4444 --pixel-format=yuva444p10le --image-format=png
```

### Blender（3D 片名）

文字物体 → 挤出 + 倒角 → 金属/锈蚀材质（噪波纹理混合）→ HDRI 打光 → 摄影机 3–5s 极慢推近，或用几何节点从文字网格发射粒子做聚散。渲染 RGBA 的 PNG 序列（24fps），在 DaVinci/AE 里叠到背景上，冲击帧对拍。

### title_card.py（本 skill 自带）

不用开 AE 就能出字卡，适合 animatic 和简单成片。预设：`fade` 推近淡入、`slam` 砸入、`glitch` 故障、`sweep` 光扫、`split` 双色（文字里用 `|` 分段）。支持纹理填充（`--texture` 一张图或一帧画面填进字里）、背景图/视频、ProRes 4444 透明导出。用法见 SKILL.md 脚本速查。

## 片名设计流程

1. 定方向：题材 + 一个材质词（锈铁、墨迹、青铜、霓虹、血、冰）。
2. 字形：书法/定制字找书法家或用 GPT-image-2 生成字形（中文字形它比 MJ 准），挑一个再矢量化（AI 的图像描摹 / Inkscape）；英文副标题用拉开字距的无衬线。
3. 材质背景：MJ 或 GPT-image-2 出纹理底（锈铁、宣纸、岩石）。
4. 动效：选上表一种主动效 + 一种辅助（如 slam + 光扫），冲击帧对拍。
5. 片名后接尾钩，不要直接黑。
