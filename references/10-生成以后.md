# 10 生成以后：小测、看片、挑片、入点、逐刀返修

视频生成回来以后的活，常常比写提示词还多。一支 AI MV 的实战记录（《Red Line》，86 刀）：计划生成 53 条，实际约 200 条（小测、双种子、重跑都算上），按镜号逐刀返修了 5 轮。预告片镜头更碎，只会更多。

顺序固定：**小测 → 批量 → 看片挑片 → 填入点出粗剪 → 按镜号逐刀返修**。

## 先小测，再批量

- 每种跑法（参考生视频、首帧生视频、首尾帧、多参考对白）各挑 1–2 条最难的先跑：对白近景、主角特写、奇观运镜、人从门里走出来、正顶俯拍。
- 看清这个模型这次的毛病，对照 07 的避坑清单改好写法，再批量写提示词。
- 批量时每批单独存一份提交记录；下载时只取这一批（混在一起，前几批会被重下一遍）。
- **提交生成只在用户明说"跑 / 生成 / 提交"时做**。写提示词、建好任务文件不花钱，提交才花工作站时间或画布额度。

## 看什么、怎么看

别在缩略图上下结论，别按整个画面的平均值下结论，别按提示词写的时间定入点。

| 要确认的 | 怎么看 | 实战里看错过的 |
|---|---|---|
| 动作做没做（抬眼、回头、拔剑、推掌） | 把脸、手放大裁出来，逐帧看（`fx.py sheet --every-frame`） | 缩略图上把"抬眼""转头"看成没做，白白重跑两条 |
| 人对不对 | 对照设定卡：脸、发型、下装、配饰、专属细节（痣、伤疤、信物） | 只给上半身参考时，下装每个种子都不一样；首帧图里替身戴的眼镜去不掉 |
| 对白嘴型 | 放大看嘴在不在动、是不是只有说话人张嘴、有没有被手或道具挡住 | 用脸部关键点量嘴的开合，数很低但看片是对的——以看片为准 |
| 穿帮 | 走的方向、东西是不是自己动了、人是不是凭空出现、群众是不是盯着镜头、画面里有没有长出字 | 人倒着走；柱子自己倒；门口的人凭空浮现；墙上冒出乱码字 |
| 景别 | 第一秒是不是就是要的景别，有没有先给一段远景再推近 | 近景提示词写了地面 → 先出全身远景 |
| 灯光变化 | 按画面里灯的位置分区看亮度，不看整个画面的平均亮度 | 按平均亮度判成"整体变亮"，其实灯是由远到近一排排亮的 |
| 画质 | 原尺寸看，别看放大或压缩过的版本；看脸上有没有鳞片纹、背景人脸歪没歪 | 二次精修让画面变脏，用户以为是模型本身的问题 |

- 每条都看完再挑，别看到第一条能用就停。
- 拿不准的动作，把那几帧截给用户看，别凭印象说"做了"。

## 挑种子

同一条提示词换个随机数（种子）再跑，结果会差很多。

- 动作镜头：比动作幅度、干不干净、落点在不在要的位置；开头有没有多余的停顿。
- 对白镜头：嘴在动、只有说话人张嘴、没被挡住；声线和这个角色的参考音频像不像。
- 两个差不多时，选**镜头更稳、景别更接近分镜表**的那个。
- 两个都不行：先查是提示词的问题（07 避坑清单）还是首帧图的问题（06 首帧图规则），改了再跑，别只换种子硬跑。

## 找入点（成片取段）

入点 = 这一镜从素材第几秒开始用。

1. **按动作实际发生的时间定**，不按提示词写的时间。实测动作常比写的晚 0.5–1.5 秒。先找到"这一镜要的那一下"（剑出鞘、回头、火光炸开）在素材第几秒，再往前倒推这一镜的长度。
2. **入点别从第 0 帧开始，也别定格第 0 帧**。生成视频第 0 帧到第 1 帧常常跳一下，看着像卡顿。从 0.05 秒以后开始用；要定格就定格动作停稳的那一帧。`animatic.py` 遇到入点写 0 的视频会提醒。
3. **落点对冲击**：入点 = 动作落点在素材里的秒数 − 落点在这一镜里的秒数。要砸在拍上的镜头，落点放在这一镜的第一帧或最后一帧前 1 帧。
4. **一条给几镜**：同一条的前段、后段分给不同镜头（07"一条服务多个镜头"），比切两条长得很像的素材顺。
5. **模型自己切了一刀**：落在用不上的地方就不管；落在要用的段落里就避开。
6. **动作差一点不在拍上**：剪辑里加速、倒放、定格一帧来凑，不重跑。
7. 填进分镜表的"素材 / 入点"两列；入点和分镜原计划不一样的，在挑片结果里标 ★。

## 填进粗剪

- 每次出粗剪都出两版：**干净版** + **镜头号版**（`animatic.py --label`，每镜左下角压镜号和这一镜在片里的起点）。用户看镜头号版，按镜号说改哪刀。
- 还没生成的镜头，素材留空，自动出占位卡，片子照样能从头看到尾。
- 成片前去掉镜头号；镜头号版只给返修用。

## 逐刀返修

用户按镜号给意见（常常一次二十几条）。每条先分类，再排顺序：

| 类 | 例 | 成本 |
|---|---|---|
| **只改剪辑** | 换入点、换同一条里没用过的段、换另一个种子、改时长、加冲推 / 闪白 / 口吃剪 / 残影 | 不花钱 |
| **重跑** | 改提示词、换种子、换跑法 | 花生成 |
| **重出图** | 首帧图构图不对、图里有字、人站错位置、带了多余配饰 | 花出图 + 生成 |
| **换模型 / 局部修** | 这个模型就是做不好，换 H3 或 Seedance；只坏一小段的交给 video-local-edit 局部修 | 花生成 |

- 先列一张"每刀怎么改、分几批"的表给用户确认，再按 **剪辑 → 重跑 → 重出图 → 换模型** 的顺序做，先做不花钱的。
- 用户嫌难看又说不出原因时，对照 `rubrics/分镜检查清单.md` 的 E 类（穿帮、意义不明、重复、太平、静图太死、接得不顺）。
- **改完自己核对**：把改动那几镜的帧截出来（`fx.py sheet`）确认改到了，再说改好了。
- 每轮改完重出镜头号版；意见和改法追加进挑片结果。旧版本素材、旧图都留着，不覆盖——用户常改主意，一镜可能视频版、静图版来回换。

## 记下来

- 每批一份挑片结果（`assets/挑片结果模板.md`），放在这批素材的文件夹，起名 `结果.md`：每镜用哪条、入点、为什么、毛病，不能用的也写上为什么。
- 这批看出来的规律单独写一节（例："近景写了地面就拉远"），下一批写提示词前先看。
- 项目根目录的 `进度记录.md`（`assets/进度记录模板.md`）随时更新：做到哪、每镜用哪条、入点多少、为什么。新开对话读它就能接着做。
