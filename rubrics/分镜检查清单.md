# 分镜检查清单（交分镜表、提示词前过一遍；E 类每轮返修后也过一遍）

## A. 能不能生成

- [ ] 每条生成条目（V）都满足"四个一"：一个机位起止、一个主运镜、一条连贯动作链（≤2–3 个小动作，各写时间点）、一套光
- [ ] 每条都写了运镜的**起点 → 方向 → 终点 + 速度**
- [ ] 每一镜都标了制作级别 L1–L4；能复用已有 V、能用 L1 / L2 做的没有新增 L3；分镜表后面附了分级统计
- [ ] 字卡、片名、频闪、闪白、变速、大角度旋转都在 L1，没写进生成提示词
- [ ] 每条都带了**质感句**；有人物的带了**人物锚点句**，和全片一字不差，写了下装和配饰
- [ ] 对白近景都写了台词原文、带了这个角色的参考音频；不说话的近景写了不说话
- [ ] 首帧图是目标景别、动作开始前的姿势、位置写死、图里没有字、没有多余配饰（06）
- [ ] 提示词对过一遍避坑清单（07）：近景没写地面、没写"全身"、没写"看不清面部"，群众写了在干什么看哪里，走路写了朝向，写了"正常速度"
- [ ] 每条写了成片取段，动作峰值在第 1.5–3 秒，时长不超过模型上限
- [ ] 每条都写了"不要背景音乐"
- [ ] 难镜头（多人同框精细动作、手和道具互动、正顶俯拍、首尾帧推穿）给了降级办法或备选

## B. 剪辑是否成立

- [ ] 每一镜都标明了来源：V 几第几秒 / 哪张图 + 怎么动 / 字卡
- [ ] 相邻两镜景别不同，或机位、明暗明显变化（点名蒙太奇例外）
- [ ] 字卡、片名、大冲击和拍点同帧（±1 帧），关键刀提前 1 帧
- [ ] 第三幕加速，段与段之间有 1–1.5s 的大镜头换气
- [ ] 片名前有 drop，片名后有尾钩
- [ ] 台词尾音没被硬切掐掉（留 4–8 帧）；跨镜的台词（L-cut）写清楚
- [ ] 转场以硬切为主，其余转场只当标点
- [ ] 视线和运动方向符合 180° 轴线

## C. 预告片感

- [ ] 看完知道三件事：什么世界、主角要面对什么、为什么现在必须看
- [ ] 有 1 个能截图当封面的招牌镜头
- [ ] 母题镜头出现 ≥3 次
- [ ] 片名前的长停 2–8 秒，镜头内部有变化（极慢推近、焦点转移、表情慢慢变）
- [ ] 剧透红线没破

## D. 交付完整

- [ ] 分镜表、素材清单、视频提示词、分级统计都齐
- [ ] 不确定的地方写进了"备注"；用了哪些默认值说明了

## E. 用户看片时最常挑的毛病

- [ ] **穿帮**：人凭空出现、东西自己动、走反方向、群众死盯镜头、动作和人设冲突（人设里本来就有的伤疤、纹样，又写他"画上去"）
- [ ] **意义不明**：每一镜都说得出"观众看到这一镜明白什么"；抽象母题插入前后有交代，不是凭空一滴水
- [ ] **慢动作 / 黑场**：有人物的慢动作、幕中间的黑场都有说得出的理由（片名前 drop、幕间换气这类常规位置不算）
- [ ] **重复**：相邻几镜不是同一个人、同一种拍法、同一个场景（同一镜头的延续除外）；没有两镜内容差不多
- [ ] **太平**：该快的段落每一拍都有东西（切、冲推、闪、动作落点）
- [ ] **静图太死**：人像静图在 0.5 秒以内，并且带推镜 / 残影 / 错位这类代码运动
- [ ] **接得不顺**：两镜之间动作、方向、光衔接得上；入点没从素材第 0 帧开始，没定格第 0 帧
- [ ] **画质**：没被二次精修弄脏、没被放大模型改脸、重新导出的码率不低于素材

> A 类有任何一条不通过，改完再交。B、C、E 类不通过超过 3 条，建议重排这一段的节奏或重做这几镜。
